# Git va GitHub — 0 dan jamoagacha

O'zbek tilida bepul Git va GitHub kursi. Hech narsa bilmaslikdan boshlab, ish joyida
jamoa bilan ishonchli ishlash darajasigacha.

**👉 Kursni ochish: [shamuratov098.github.io/git-kursim](https://shamuratov098.github.io/git-kursim/)**

Ro'yxatdan o'tish, yuklab olish, o'rnatish kerak emas — oddiy sayt. Telefon, planshet
va kompyuterda bir xil ochiladi.

---

## Kimga mo'ljallangan

- Git bilan **hech qachon ishlamagan** yoki `git add`dan nariga o'tmagan dasturchilarga
- Ish joyida yoki jamoada kod ustida ishlashni boshlayotganlarga
- Inglizcha materialdan ko'ra **o'zbekcha** o'qishni qulay ko'radiganlarga

Har bir dars bitta aniq ko'nikma beradi va o'zidan oldingisiga tayanadi. Tartib bilan
borish tavsiya qilinadi.

## Kurs ikki rejimda ishlaydi

Har bir dars sahifasining tepasidagi tugma bilan rejim almashtiriladi. Tanlov eslab
qolinadi va barcha darslarga tarqaladi.

| 📱 **O'qish** | 💻 **Amaliyot** |
|---|---|
| Telefon uchun | Kompyuter uchun |
| Kattaroq shrift, tushuntirishlar | Qadam-baqadam yo'riqnoma |
| «Eslab ayting» kartalari | **Copy** tugmasi va kutilgan natijalar |
| Terminal qadamlari yashirin | Belgilab boriladigan checklist |

Odatiy tartib: **yo'lda telefonda o'qiysiz**, **uyda kompyuterda bajarasiz**. Bir
mavzuga ikki xil holatda qaytish — bilimni uzoq saqlashning eng ishonchli yo'li.

Kechqurun ochsangiz qorong'i rejim avtomatik yoqiladi. Darslarni bosib chiqarsa ham
bo'ladi — shu uchun alohida formatlangan.

## Texnik jihat

Oddiy HTML, CSS va JavaScript. Framework yo'q, build qadami yo'q, tashqi kutubxona yo'q.
Butun sayt ~477 KB — sekin internetda ham bir zumda ochiladi.

```
index.html          — bosh sahifa
lessons/            — darslar
reference/          — lug'at, buyruqlar varaqasi, yo'l xaritasi
assets/styles.css   — umumiy stil (ikki rejim, qorong'i rejim, print)
assets/app.js       — rejim almashtirish, quiz, Copy tugmasi
```

Mahalliy ochish uchun repo'ni clone qilib `index.html` ni brauzerda oching — server
kerak emas.
