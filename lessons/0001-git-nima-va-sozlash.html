DARS 01 · GIT ASOSLARI

Git nima, nega kerak — va kompyuterni tayyorlash

Bu darsdan keyin siz Git nimaligini bir jumlada tushuntira olasiz va kompyuteringiz jamoada ishlashga tayyor bo'ladi — har bir commit aynan sizniki ekanini Git biladi.

📱 O'qish ≈ 6 daqiqa 💻 Amaliyot ≈ 8 daqiqa Daraja: boshlang'ich

Nega bu muhim (sizning maqsadingiz)

Jamoada bir nechta odam bitta loyiha ustida ishlaydi. Git bo'lmasa: fayllar loyiha_final_FINAL_v2.zip ga aylanadi, kim nimani buzganini bilib bo'lmaydi, va birovning ishi ustiga yozib yuborish oson. Git aynan shu muammoni yo'qotadi — shuning uchun deyarli har bir ish joyida Git talab qilinadi.

Git aslida nima qiladi?

Git — bu version control system (versiyalarni boshqarish tizimi). Sodda qilib: Git loyihangizning holatini vaqt-vaqti bilan rasmga olib (snapshot) saqlab boradi. Har bir bunday saqlangan holat — commit deyiladi.1

Har bir commit — loyihangizning to'liq holati (faqat farqi emas).2 Shu sababli istalgan vaqtda ortga qaytib, "kecha hammasi ishlayotgan edi" degan holatga bemalol borasiz.

Bitta commit ichida nima saqlanadi?

Commit — shunchaki fayllar nusxasi emas. Uning ichida to'rt narsa bor:

  • Snapshot — o'sha ondagi barcha fayllar holati.
  • Muallif — kim qildi (ism + email). Buni hozir sozlaymiz.
  • Vaqt — qachon qilindi.
  • Izoh (message) — nima va nega o'zgardi.

Mana shu to'rtlik tufayli, oradan olti oy o'tib ham git log ga qarab "bu qatorni kim, qachon va nega yozgan?" degan savolga javob topasiz. Jamoada bu — oltin qiymatga ega.

Tarqoq (distributed) degani

Git'da har bir dasturchining kompyuterida loyihaning butun tarixi to'liq bo'ladi — faqat oxirgi versiya emas, hamma commitlar. Shuning uchun internet bo'lmasa ham ishlayverasiz: commit qilasiz, tarixni ko'rasiz, ortga qaytasiz. GitHub esa shu nusxalarni bir-biriga ulaydigan umumiy markaz vazifasini bajaradi (buni 4-darsda ko'ramiz).

Kompyuterni tayyorlash: 2 ta narsa

Git ishga tushishi uchun jami ikkita narsa kerak: (1) Git o'rnatilgan bo'lsin, (2) Git sizning ismingiz va emailingizni bilsin. Bo'ldi. Quyida shu ikkisini qilamiz.

1 — Git o'rnatilganini tekshirish

Terminalda git --version yozasiz. Agar versiya raqami chiqsa — Git bor va ishlayapti.3

git --version git version 2.43.0

2 — Git'ga o'zingizni tanishtirish

Git har bir commitga "muallif" sifatida sizning ism va emailingizni yozadi. Buni bir marta sozlab qo'yamiz:3

git config --global user.name "Ismingiz Familiyangiz"
git config --global user.email "siz@example.com"

Bu yerda har bir bo'lakning ma'nosi bor:

  • git config — Git sozlamalarini o'zgartirish buyrug'i.
  • --global — "shu kompyuterdagi barcha loyihalar uchun". Bu sozlama uy papkangizdagi ~/.gitconfig fayliga yoziladi. Agar --global yozmasangiz, sozlama faqat shu bitta loyiha uchun bo'ladi — ish va shaxsiy loyihalarda turli email ishlatish uchun qulay.
  • user.name / user.email — sozlamaning nomi.
Jamoa uchun muhim nuqta

Bu yerdagi email GitHub akkauntingiz email'i bilan bir xil bo'lsin. Shunda qilgan commitlaringiz GitHub'da sizning profilingizga bog'lanadi — ish/jamoada "kim nima qildi" aniq ko'rinadi.4 Email mos kelmasa, commit baribir saqlanadi, lekin GitHub uni "noma'lum odam" deb ko'rsatadi. (GitHub'ingiz hali bo'lmasa — hech qisi yo'q, keyinroq ochamiz va shunda moslaymiz.)

Amaliyot: hozir terminalda bajaring

Terminalni oching (Ubuntu'da Ctrl+Alt+T) va quyidagilarni birma-bir bajaring. Har buyruqning o'ng tomonidagi Copy tugmasi bilan nusxa oling — terish xatolari bo'lmaydi.

  1. Git borligini tekshiring

    Nima uchun: keyingi hamma narsa shunga tayanadi.

    git --version

    Kutilgan natija: git version 2.43.0 kabi qator. Agar "command not found" chiqsa — menga ayting, birga o'rnatamiz.

  2. Ismingizni yozing

    Tirnoq ichidagi matnni o'zingiznikiga almashtiring.

    git config --global user.name "Ismingiz Familiyangiz"

    Kutilgan natija: hech qanday javob chiqmaydi. Git'da jimlik — bu muvaffaqiyat belgisi. 🙂

  3. Email'ingizni yozing

    Iloji bo'lsa GitHub akkauntingizdagi email bilan bir xil bo'lsin.

    git config --global user.email "siz@example.com"

    Kutilgan natija: yana jimlik.

  4. Sozlamani tekshiring

    Ishonch hosil qilamiz: Git haqiqatan sizni eslab qoldimi?

    git config --global --list user.name=Ismingiz Familiyangiz user.email=siz@example.com

    Kutilgan natija: ro'yxatda o'z ism va email'ingizni ko'rasiz. Uzun ro'yxat chiqsa — chiqish uchun q tugmasini bosing.

  5. (Ixtiyoriy) Asosiy branch nomini main qiling

    Yangi loyihalarda hozirgi standart nom — main. Bu sozlamasiz Git eski master nomini ishlatadi.

    git config --global init.defaultBranch main

    Kutilgan natija: jimlik. Bundan keyin git init avtomatik main branch yaratadi.

Yodda tuting (checklist)

💻 Amaliy qism kompyuterda

Bu darsning amaliyoti — yuqoridagi 3 ta buyruqni terminalda yozish (git --version, keyin ikkita git config). Kompyuterda ochganingizda qadam-baqadam yo'riqnoma, Copy tugmasi va kutilgan natijalar chiqadi.

✓ Sizning g'alabangiz

Git o'rnatilgan, ishlayapti, va endi sizni taniydi. Bundan keyin qiladigan har bir commit aniq sizning nomingiz bilan yoziladi. Bu — jamoada ishlashning birinchi poydevori. 🎉

Tekshirib ko'ramiz (quiz)

Eslab javob berish — bilimni mustahkamlaydigan eng yaxshi usul. Shoshilmang, o'ylab tanlang.

SAVOL 1 Git loyihangizni qanday saqlaydi?

To'g'ri — har commit loyihaning o'sha ondagi to'liq holati (snapshot). Shuning uchun istalgan eski holatga qaytish oson.

SAVOL 2 Nega jamoada (team) Git ayniqsa muhim?

Aynan — Git ko'p kishining o'zgarishlarini yo'qotmasdan, bir-birini buzmasdan birlashtirishga imkon beradi.

SAVOL 3 git config user.email nima uchun kerak?

To'g'ri — email commit muallifini belgilaydi. GitHub email'i bilan bir xil bo'lsa, commitlar profilingizga bog'lanadi.

Eslab ayting (o'zingizni sinang)

Avval o'zingiz javob bering (ovoz chiqarib bo'lsa ham), keyin ochib tekshiring. Javobni ko'rishdan oldin eslab ko'rish — xotirani eng kuchli mustahkamlaydigan usul.

Git nima qiladi — bir jumlada?

Loyihaning holatini vaqt-vaqti bilan snapshot qilib saqlaydi va har bir snapshot'da kim, qachon, nima, nega o'zgartirganini yozib qo'yadi.

Bitta commit ichida qaysi 4 narsa bor?

Snapshot (fayllar holati) · muallif (ism + email) · vaqt · izoh (message).

--global nimani anglatadi?

"Shu kompyuterdagi barcha loyihalar uchun". Sozlama ~/.gitconfig faylida saqlanadi. --globalsiz esa sozlama faqat joriy loyihaga tegishli bo'ladi.

Buyruq yozdim, hech qanday javob chiqmadi. Xatomi?

Yo'q — Git'da jimlik = muvaffaqiyat. Xato bo'lsa, Git albatta xabar yozadi.

Sozlamani qaysi buyruq bilan tekshiraman?

git config --global --list — ro'yxatda user.name va user.email ko'rinadi.

Cho'ntak xulosasi
  • Git = loyihaning snapshot'lari + kim/qachon/nega yozuvi.
  • commit = bitta saqlangan holat (tarixning bir qadami).
  • Distributed = butun tarix har bir kompyuterda; internetsiz ham ishlaydi.
  • git --version → Git bormi?
  • git config --global user.name / user.email → Git meni tanisin.
  • Email GitHub email'iga mos bo'lsin → commitlar profilingizga bog'lanadi.
