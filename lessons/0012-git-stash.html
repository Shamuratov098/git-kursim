DARS 12 · QO'SHIMCHA · KURSDAN KEYIN

git stash: yarim ishni vaqtincha yig'ib qo'yish

Bu darsdan keyin siz tugallanmagan ishni commit qilmasdan xavfsiz yig'ib qo'yasiz, boshqa ish bilan shug'ullanasiz va keyin uni joyiga qaytarasiz — hech narsa yo'qotmasdan.

📱 O'qish ≈ 8 daqiqa 💻 Amaliyot ≈ 14 daqiqa Kerak: 11 darslik asosiy kurs

Bu — kursdan keyingi birinchi dars

Asosiy 11 dars missiyangizni to'liq qopladi. stash esa qulaylik asbobi: usiz ham ishlash mumkin, lekin u bilan ancha yengil. 11-darsda «keyingi o'rganadiganingiz shu bo'lsin» deganim — mana shu.

Muammo: siz allaqachon uchratgansiz

Ikki holatni eslang:

  • 6-darsda: «Branch almashishdan oldin ishingizni commit qiling» — chunki saqlanmagan o'zgarish bo'lsa, Git almashishga ruxsat bermasligi mumkin.
  • 10-darsda: «kun boshi git pull» — lekin qo'lingizda yarim ish tursa, pull ham to'sqinlikka uchraydi.

Ikkalasida ham yechim bir xil edi: commit qiling. Lekin nima qilasiz, agar ishingiz commit qilishga hali tayyor bo'lmasa?

Odatdagi vaziyat

Siz yangi funksiya ustida ishlayapsiz — yarmi yozilgan, hali ishlamaydi. Shu payt hamkasbingiz yozadi: «saytda shoshilinch xato bor, tuzatib yuborasanmi?»

Endi tanlov: yarim ishni wip degan axlat commit qilib tarixni ifloslantirasizmi, yoki o'zgarishlarni yo'qotasizmi? Uchinchi yo'l bor — stash.

stash nima — restoran metaforasida

2-darsdagi restoran esingizdami? Oshxona = ish papkasi, podnos = saralash joyi, mijoz stoli = tarix.

Stash = sovutgich 🧊

Yarim pishgan taomni sovutgichga qo'yasiz. Oshxona bo'shaydi — shoshilinch buyurtmani bemalol bajarasiz. Keyin sovutgichdan qaytarib olib, qolgan joyidan davom etasiz.

Muhimi: sovutgich buyurtmalar oqimidan tashqarida. Mijozga hech narsa berilmadi — ya'ni tarixingizga hech narsa yozilmaydi.

Texnik tilda: git stash ish papkangiz va saralash joyidagi o'zgarishlarni olib qo'yadi va alohida saqlaydi. Papkangiz oxirgi commit holatiga qaytadi — toza bo'ladi.1

Buyruqlar

BuyruqNima qiladi
git stash O'zgarishlarni javonga qo'yadi, papkangiz tozalanadi.
git stash push -m "izoh" Xuddi shu, lekin nom bilan. Bir nechta stash bo'lganda qaysi biri nima ekanini eslashga yordam beradi. Tavsiya qilaman.
git stash list Javonda nima borligini ko'rsatadi. ✓ Xavfsiz, faqat ko'rsatadi.
git stash show -p Oxirgi stash ichida nima borligini satrma-satr ko'rsatadi (git diff kabi).
git stash pop Oxirgisini qaytaradi va javondan olib tashlaydi. Eng ko'p ishlatiladigan.
git stash apply Qaytaradi, lekin javonda ham qoldiradi.
git stash drop Oxirgisini qaytarmasdan o'chiradi.
git stash clear ⚠️ Javonni butunlay bo'shatadi. Qaytarib bo'lmaydi — ehtiyot bo'ling.

pop va apply farqi

Bu — eng ko'p chalkashtiriladigan juftlik. Farqi bitta narsada:

  • pop = olib qo'yish. Ishingiz qaytadi, javon bo'shaydi. Odatda shu kerak.
  • apply = nusxa olish. Ishingiz qaytadi, lekin javonda ham qoladi. Bir xil o'zgarishni ikki xil branch'ga qo'llamoqchi bo'lsangiz yoki «ehtiyot uchun» nusxa qoldirmoqchi bo'lsangiz foydali.
Javon — bu tartiblangan ro'yxat

Bir nechta stash qilsangiz, ular raqamlanadi: eng oxirgisi stash@{0}, undan oldingisi stash@{1} va hokazo. Aniq birini olish uchun: git stash pop stash@{1}.

Eng foydali stsenariy: noto'g'ri branch'da ishlab qo'yish

10-darsda «mainda adashib commit qilib qo'ydim» holatini ko'rgan edik — u yerda reset --hard kerak bo'lgandi.

Agar hali commit qilmagan bo'lsangiz, hammasi ancha oson. Uch buyruq:

git stash # ishni javonga qo'y
git switch -c to-g-ri-branch # to'g'ri joyga o't
git stash pop # ishni qaytarib ol

Stash branch'ga bog'lanmagan — ya'ni bir branch'da qo'yib, boshqasida olishingiz mumkin. Aynan shu xususiyat bu stsenariyni ishlatadi.

Ikkita muhim ogohlantirish

1. Yangi (untracked) fayllar stash qilinmaydi

Endigina yaratgan, hali hech qachon git add qilinmagan fayl javonga tushmaydi — u joyida qolaveradi. Sabab: Git uni hali kuzatmaydi (2-dars: untracked).

Ularni ham qo'shmoqchi bo'lsangiz — -u qo'shing:

git stash -u -m "yangi fayllar bilan"
2. Stash — zaxira nusxa EMAS

U faqat sizning kompyuteringizda turadi. Hech qachon push qilinmaydi, GitHub'da ko'rinmaydi, hamkasbingizga yetib bormaydi.

Shuning uchun qoida: stash — bir necha soatlik javon, bir haftalik ombor emas. Ish muhim bo'lsa yoki uzoqqa cho'zilsa — branch ochib commit qiling (6-dars). Commit qilingan narsa xavfsiz (oltin qoida), stashdagi narsa esa unutilib ketishga moyil.

Amaliyot: javonni ishlatib ko'ramiz

Mashq nusxa papkada (~/Projects/Learn/Git-nusxa) — bu bizning xavfsiz mashq maydonimiz. Push yo'q, hammasi mahalliy.

Nusxa papkangiz yo'qmi?

5-darsning 1–2-qadamini bajaring (bitta git clone). Yoki menga ayting.

A qism — asosiy aylana

  1. Tayyorgarlik: kuzatiladigan fayl yarating

    Stash kuzatilayotgan fayllar bilan ishlaydi, shuning uchun avval commit qilamiz.

    cd ~/Projects/Learn/Git-nusxa && git switch main && echo "Birinchi qator." > ish.txt && git add ish.txt && git commit -m "Ish fayli qo'shildi"

    Kutilgan natija: 1 file changed.

  2. «Yarim ish» qiling

    Bu — tugallanmagan, commit qilishga tayyor bo'lmagan ish.

    echo "Yarim tugagan ish..." >> ish.txt && git status --short M ish.txt

    Kutilgan natija: M ish.txt — o'zgargan, lekin commit qilinmagan.

  3. 🧊 Javonga qo'ying

    Nom bilan qo'yish yaxshi odat.

    git stash push -m "yarim ish" Saved working directory and index state On main: yarim ish

    Kutilgan natija: «Saved working directory». Endi git status deng — working tree clean! cat ish.txt deng — yarim ish yo'q. 1-g'alaba. 🎉

  4. Javonda nima borligini ko'ring

    git stash list && git stash show -p stash@{0}: On main: yarim ish +Yarim tugagan ish...

    Kutilgan natija: ro'yxatda bitta stash va uning ichidagi + belgili qator. Chiqish: q.

  5. «Shoshilinch ish»ni bajaring

    Papkangiz toza — bemalol boshqa ish qilasiz.

    echo "Shoshilinch tuzatish." > shoshilinch.txt && git add shoshilinch.txt && git commit -m "Shoshilinch xato tuzatildi"

    Kutilgan natija: commit yaratildi — toza tarix, hech qanday wip axlat commit yo'q.

  6. Yarim ishni qaytarib oling

    pop = qaytar va javondan olib tashla.

    git stash pop modified: ish.txt Dropped refs/stash@{0}

    Kutilgan natija: «Dropped» — javon bo'shadi. cat ish.txt deng — yarim ishingiz qaytdi. git stash list — bo'sh. 2-g'alaba. 🎉

B qism — noto'g'ri branch'dan qutqarish

Eng foydali stsenariy. Hozir siz maindasiz va qo'lingizda commit qilinmagan ish bor — aslida u branch'da bo'lishi kerak edi.

  1. Holatni tasdiqlang

    «Voy, men mainda ishlab yuribman!»

    git branch --show-current && git status --short main M ish.txt

    Kutilgan natija: main va o'zgargan fayl. Aynan tuzatiladigan holat.

  2. Javonga qo'ying

    git stash push -m "branchga ko'chiriladigan ish"

    Kutilgan natija: «Saved...». main toza.

  3. To'g'ri branch oching

    git switch -c ish-branchi Switched to a new branch 'ish-branchi'

    Kutilgan natija: yangi branch. Hozircha bo'sh.

  4. Ishni shu yerga qaytaring

    Stash branch'ga bog'lanmagan — shuning uchun bu ishlaydi.

    git stash pop && git status --short M ish.txt

    Kutilgan natija: ishingiz endi to'g'ri branch'da. Uni bemalol commit qiling. 3-g'alaba. 🎉

C qism — untracked tuzog'i

  1. Yangi fayl yarating va oddiy stash qiling

    Bu fayl hali hech qachon add qilinmagan — ya'ni untracked.

    echo "Yangi fayl" > yangi.txt && git stash push -m "sinov" && ls yangi.txt yangi.txt

    Kutilgan natija: yangi.txt hali ham joyida! Stash uni olmadi — chunki u untracked.

  2. Endi -u bilan qiling

    -u = untracked fayllarni ham qo'sh.

    git stash push -u -m "untracked bilan" && ls yangi.txt ls: cannot access 'yangi.txt': No such file or directory

    Kutilgan natija: endi fayl ham javonga tushdi — ls uni topa olmaydi. Bu xato emas, kutilgan natija. Qaytarish: git stash pop. 4-g'alaba. 🎉

  3. Javonni tozalab, mashqni yakunlang

    Ikkita stash qolgan — ro'yxatni ko'rib, qaytaramiz.

    git stash list stash@{0}: On ish-branchi: untracked bilan stash@{1}: On ish-branchi: sinov

    Kutilgan natija: ikkita stash. Ikki marta git stash pop qilsangiz — ikkalasi ham qaytadi va javon bo'shaydi.

Mashqdan keyin

Nusxa papkangizni tartibga solmoqchi bo'lsangiz — ayting, birga qilamiz. Bu papka faqat mashq uchun, shuning uchun undagi holat muhim emas.

Yodda tuting (checklist)

💻 Amaliy qism kompyuterda

Amaliyotda «yarim ish» yaratib uni javonga qo'yasiz, papkangiz tozalanganini ko'rasiz, shoshilinch ishni bajarasiz va yarim ishni qaytarib olasiz. Keyin eng foydali stsenariy: noto'g'ri branch'da ishlab qo'ygan ishni stash → switch → pop bilan to'g'ri joyga ko'chirasiz. Oxirida untracked tuzog'ini ko'rasiz. 13 qadam, hammasi nusxa papkada.

Tekshirib ko'ramiz (quiz)

SAVOL 1 git stash qilgandan keyin ish papkangiz qanday bo'ladi?

To'g'ri — o'zgarishlar olib qo'yiladi va javonda saqlanadi. Shuning uchun bemalol branch almashasiz yoki pull qilasiz.

SAVOL 2 pop va apply farqi nimada?

To'g'ri. pop = olib qo'yish, apply = nusxa olish. Odatda pop kerak bo'ladi.

SAVOL 3 Endigina yaratgan yangi faylni stash qilmoqchisiz. Nima qilasiz?

To'g'ri. Oddiy stash faqat kuzatilayotgan fayllarni oladi — yangi fayl joyida qolaveradi.

SAVOL 4 Uzoq davom etadigan muhim ishni qayerda saqlaysiz?

To'g'ri. Stash — bir necha soatlik javon, ombor emas. U faqat kompyuteringizda turadi va push qilinmaydi. Muhim ish uchun — branch + commit.

Eslab ayting (o'zingizni sinang)

Avval o'zingiz javob bering, keyin ochib tekshiring.

Stash restoran metaforasida nima edi?

Sovutgich 🧊 — yarim pishgan taomni qo'yib turasiz, shoshilinch buyurtmani bajarasiz, keyin qaytarib olasiz. Buyurtmalar oqimidan tashqarida — ya'ni tarixga hech narsa yozilmaydi.

Stash qachon kerak bo'ladi?

Ish commit qilishga tayyor emas, lekin branch almashish, pull qilish yoki shoshilinch boshqa ishni bajarish kerak bo'lganda.

Noto'g'ri branch'da ishlab qo'ydingiz (commit qilmagan). Uch buyruq?

git stash → git switch -c to-g-ri-branch → git stash pop. Ishlaydi, chunki stash branch'ga bog'lanmagan.

pop va apply — qaysi biri javonni bo'shatadi?

pop. apply esa qaytaradi, lekin javonda ham qoldiradi.

Stash zaxira nusxa bo'la oladimi?

Yo'q. U faqat kompyuteringizda turadi, hech qachon push qilinmaydi. Muhim yoki uzoq ish uchun — branch ochib commit qiling.

↩︎ Takrorlash: Git'ning oltin qoidasi?

Commit qilingan narsani yo'qotish juda qiyin, commit qilinmaganini esa oson — stash ham shu ikkinchi toifada. (Dars 03)

Cho'ntak xulosasi
  • Stash = javon (sovutgich): yarim ishni commit qilmasdan olib qo'yadi, papkangiz tozalanadi.
  • git stash push -m "izoh" — nom bilan qo'yish (tavsiya) · git stash list — ko'rish · git stash show -p — ichini ko'rish.
  • pop = qaytar va o'chir · apply = qaytar, javonda qoldir.
  • Noto'g'ri branch'dan qutqarish: stash → switch -c → stash pop.
  • Untracked fayllar uchun -u shart.
  • ⚠️ Stash zaxira emas — push qilinmaydi. Uzoq ish uchun branch + commit.
  • ⚠️ git stash clear — javonni butunlay bo'shatadi, qaytarib bo'lmaydi.
