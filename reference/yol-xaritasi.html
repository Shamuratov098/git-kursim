REFERENCE · ARXITEKTURA

Kurs yo'l xaritasi

Qayerdan boshlab qayerga boryapmiz — 11 ta dars, 4 ta modul, ustiga qo'shimcha darslar. Har bir dars bitta aniq ko'nikma beradi va o'zidan oldingisiga tayanadi.

Holat: barcha darslar yozildi 🎓 Tayyor darslar: 11 / 11 📱 O'qishga mos

Ketma-ketlik qanday tuzilgan?

Tartib tasodifiy emas. U missiyangizdan kelib chiqadi: ishda/jamoada qo'rqmasdan ishlash. Uchta qoidaga amal qilindi:

  1. Qo'rquvni erta yo'qotish. «Xatoni qaytarish» darsi boshida turadi — orqaga qaytishni bilsangiz, tajriba qilishdan qo'rqmaysiz.
  2. Har bir dars oldingisining ustiga quriladi. Hech qachon o'rganilmagan narsani ishlatmayman. Masalan merge conflict darsi mergedan keyin, merge esa branchdan keyin keladi — boshqacha bo'lishi mumkin emas.
  3. Yakkadan jamoaga. Avval o'zingiz bilan o'zingiz (Modul A), keyin internet bilan (B), keyin parallel ishlash (C), oxirida odamlar bilan (D). Jamoa qiyinchiliklari — eng oxirida, chunki ular qolgan hammasini talab qiladi.
Har bir dars ikki marta uchraydi

📱 telefonda o'qiysiz (tushuncha) → 💻 kompyuterda bajarasiz (ko'nikma). Bir mavzuga ikki xil holatda qaytish — bilimni uzoq saqlashning eng ishonchli yo'li.

Modul A

Poydevor — yakka ishlash

Maqsad: Git'ni o'z kompyuteringizda ishonch bilan boshqarasiz. Internet ham, jamoa ham hali kerak emas.

  1. 01
    Git nima va kompyuterni sozlash Git meni taniydi — har commit mening nomimda git --version · git config --global
    Tayyor
  2. 02
    3 hudud va commit aylanasi O'zgarishni tanlab, toza commit qila olaman git init · git status · git add · git commit · git log
    Tayyor
  3. 03
    Xato qildim: ko'rish va ortga qaytarish Qo'rqmayman — har uch hududdagi xatoni qaytara olaman git diff · git show · git restore · git commit --amend
    Yangi
Modul B

GitHub — ishimni internetga chiqarish

Maqsad: kompyuteringizdagi tarix GitHub bilan bog'lanadi. Ish yo'qolmaydi va istalgan joydan yetib boradi.

  1. 04
    Remote va push: ishim GitHub'da O'z ishimni GitHub'ga chiqara olaman git remote · git push · git push -u origin main
    Yangi
  2. 05
    Clone va pull: ishimni qaytarib olish Boshqa kompyuterda ham xuddi shu loyihada ishlayman git clone · git fetch · git pull
    Yangi
Modul C

Branch — parallel ishlash

Maqsad: asosiy kodga tegmasdan yangi ish qilish va uni xavfsiz qaytarib qo'shish. Jamoa workflow'ining texnik poydevori.

  1. 06
    Branch: alohida yo'lda ishlash Asosiy kodni buzmasdan yangi narsa sinayman git branch · git switch -c · git switch
    Yangi
  2. 07
    Merge: ishni asosiyga qo'shish Tugagan ishimni mainga qo'sha olaman git merge · git branch -d · git log --graph
    Yangi
  3. 08
    Merge conflict: ziddiyatni hal qilish Konflikt chiqsa vahima qilmayman — hal qilaman <<<<<<< belgilar · git merge --abort
    Yangi
Modul D

Jamoa — odamlar bilan ishlash

Maqsad: missiyaning yakuniy nuqtasi. Ish joyidagi kundalik tartibda, hamkasblar bilan birga ishlaysiz.

  1. 09
    Pull request: taklif, review, merge PR ocha olaman va boshqalarnikini ko'rib chiqaman git push -u · GitHub: PR · Files changed · Merge
    Yangi
  2. 10
    Kundalik jamoa ritmi pull → branch → commit → push → PR ni avtomatik bajaraman to'liq aylana · git merge main · rejected push · reset --hard
    Yangi
  3. 11
    Professional odatlar Toza tarix, toza repo — hamkasblarim minnatdor .gitignore · git rm --cached · commit message · README
    Yangi
Qo'shimcha

Kursdan keyin — so'ralganda qo'shiladi

Asosiy 11 dars missiyani to'liq qopladi. Bu bo'limdagilar — qulaylik asboblari: usiz ham ishlash mumkin, lekin ular bilan yengilroq. Kerak bo'lganda ayting, qo'shamiz.

  1. 12
    git stash: yarim ishni yig'ib qo'yish Tugallanmagan ishni commit qilmasdan saqlab turaman git stash push -m · list · pop · apply · -u
    Yangi
  2. 13
    git rebase: tarixni to'g'ri chiziqqa keltirish Toza, chiziqli tarix — va qachon xavfli ekanini bilaman git rebase main · --continue · --abort · pull --rebase
    Yangi
  3. 14
    git reflog: yo'qolgan ishni qaytarish «Hammasini yo'qotdim» degan holatdan chiqa olaman git reflog · HEAD@{N} · reset --hard · switch -c <hash>
    Yangi
  4. 15
    git cherry-pick: bitta commitni tanlab olish Butun branch emas, aynan kerakli commitni olaman git cherry-pick · -x · --continue · --abort
    Yangi
  5. 16
    Fork: birovning loyihasiga hissa qo'shish Open source'ga birinchi hissamni qo'shaman fork · remote add upstream · fetch upstream · PR
    Yangi
  6. 17
    rebase -i: commitlarni birlashtirish PR'dan oldin chalkash tarixni tozalayman reset --soft · rebase -i · pick/squash/fixup/reword/drop
    Yangi
  7. 18
    GitHub Actions: yashil va qizil belgilar PR'dagi avtomatik tekshiruvni tushunaman va yozaman .github/workflows · on · jobs · steps · chiqish kodi
    Yangi

Hali ham kursdan tashqarida

Bular kerak emas degani emas — hozir kerak emas degani. Kerak bo'lganda ayting, dars qo'shamiz:

  • rebase -i (commitlarni birlashtirish), bisect (xatoni ikkiga bo'lib qidirish) — kuchli, lekin xavfliroq asboblar.
  • Git internals (blob / tree / object modeli) — qiziq, lekin amaliyotga ta'sir qilmaydi.
  • CI/CD, GitHub Actions, o'z Git serveri — bular Git emas, ular Git ustiga quriladi.
Xarita o'zgarishi mumkin

Amaliyotda biror joy qiyin bo'lsa yoki ishingizda boshqa narsa kerak bo'lib qolsa — ayting, xaritani qayta tuzamiz. Bu tosh emas, reja.
